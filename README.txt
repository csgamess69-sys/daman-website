DAMAN STATIC WEBSITE — VS CODE / GITHUB / VERCEL

FILES
- index.html: home page
- style.css: responsive design
- script.js: mobile menu and download/community link settings
- privacy.html and terms.html: starter legal-page templates
- downloads/: put your real APK here

LOCAL PREVIEW
1. Extract this ZIP.
2. Open the extracted daman-website folder in VS Code.
3. Install the "Live Server" extension.
4. Right-click index.html and choose "Open with Live Server".

ADD YOUR APK
1. Put your actual APK in the downloads folder.
2. Rename it exactly: daman.apk
3. The download button points to downloads/daman.apk.
Do not use a fake, modified or unverified APK.

CUSTOMIZE BEFORE PUBLISHING
- In script.js, replace COMMUNITY_URL with your actual official join/group link.
- In index.html and legal pages, replace support@example.com with your real email.
- Update app version and description to match the real app.
- Replace the Privacy Policy and Terms templates with accurate documents.
- Add real screenshots and publisher details if appropriate.

DEPLOY
1. Create a GitHub repository and upload all files/folders, keeping the same structure.
2. In Vercel, choose Add New > Project and import that GitHub repository.
3. Framework preset: Other. Build command: leave blank. Output directory: . (root).
4. Click Deploy.
5. Test the live site's APK button on an Android phone.

IMPORTANT
This is a static information/download website template. It does not make an app legal or verify an APK. Follow applicable laws and platform policies. Do not describe the app as Google Play approved unless it actually is.
